# 🍔 BurgerArtisan - Hamburgueria Artesanal

Landing page moderna e responsiva desenvolvida para a **BurgerArtisan**, destacando o cardápio de hambúrgueres artesanais, informações sobre a casa e botões para chamadas de ação.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica do projeto.
- **CSS3**: Estilização, efeitos visuais, cores e layout responsivo.

---

## 📱 Destaques do Projeto

- Design moderno e elegante em tom escuro (*Dark Mode*).
- Exibição de cardápio com preços e fotos dos hambúrgueres.
- Layout adaptado para visualização em computadores e celulares.
- Seções bem estruturadas: Início, Cardápio e Sobre Nós.
